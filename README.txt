EDUPLAY - Explore, Learn & Play

CARA MENJALANKAN
1. Ekstrak folder EduPlay.
2. Buka folder menggunakan Visual Studio Code.
3. Buka file index.html di browser (Chrome/Edge).
   Alternatif: gunakan ekstensi Live Server di VS Code lalu klik "Go Live".

TEKNOLOGI
- HTML5
- CSS3
- Bootstrap 5 (dimuat melalui CDN, perlu internet untuk komponen dan styling Bootstrap)
- JavaScript
- LocalStorage (penyimpanan lokal browser, bukan database)

FITUR
- Beranda
- Materi pembelajaran
- Quiz Challenge
- Tebak Kata
- Cocokkan Pasangan
- Susun Kata
- Profil pemain dan penyimpanan poin lokal

CATATAN
- Skor dan nama tersimpan pada browser/perangkat yang sama.
- Belum ada akun, server, atau leaderboard online lintas perangkat.
- Konten materi dan pertanyaan masih berupa contoh dan dapat ditambah di js/app.js.
